# Marketing-Campaign-Analysis
This project analyzes marketing campaigns using data science techniques, focusing on the Four Ps of Marketing: Product, Price, Place, and Promotion. The goal is to explore consumer behavior through EDA, hypothesis testing, and visualization.

**Steps Performed**

Data Preprocessing: Missing value imputation, feature engineering (age, spending, total children).

EDA: Box plots, histograms, heatmap, outlier treatment, encoding categorical variables.

Hypothesis Testing: Consumer preferences, online vs in-store shopping, regional purchase trends.

Insights: Top/least-performing products, campaign acceptance rates, customer spending patterns.
